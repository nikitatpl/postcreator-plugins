name: postcreator-resolve
description: Редактируй таймлайн, применяй встроенную цветокоррекцию CDL/LUT и запускай ограниченный рендер Resolve официальным SDK автоматизации с явными ID активного проекта и таймлайна.
---

Локальный помощник импортирует официальный модуль найденной установки. Проверь `status` / `context.inspect`, передавай возвращённые ID проекта/таймлайна каждому изменению. Устаревшее состояние отклоняется. Импорт возвращает ID медиа; append использует их, не неоднозначные имена. До цвета выбери реальные стабильные ID элементов.

Используй `media.import`, `timeline.create` / `timeline.append`, `color.set_cdl`, `color.set_lut` для заказа. CDL-каналы ограничены, индекс цветового узла начинается с 1. LUT должен существовать и быть зарегистрирован/найден Resolve; глобальной установки и смены предпочтений нет. `render.formats` даёт реальные ключи кодеков, затем `render.queue`, `render.start`, `render.status`. Запускаются лишь задачи этой сессии с новыми файлами внутри каталога результатов. Старт не означает экспорт — проверь Complete и настоящий файл.

Для изолированной демонстрации создай новый проект с префиксом Postcreator после исследования текущего. Сохрани исходный `context`/имя. `project.restore` разрешён только для созданного этой Node-сессией активного проекта и ранее исследованного исходного проекта; передай собственный текущий `context` и точное прежнее `name`. Произвольный переход в чужой проект или другая сессия не разрешены. Восстановление не сохраняет/правит исходник; проверь возвращённую идентичность. Неопределённое завершение исследуется до повтора. Произвольный цветовой граф, автоматическое согласование кадров, удаление проектов и настройки лицензий недоступны.
