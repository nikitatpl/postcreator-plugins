---

Проверь статус приложения. Illustrator использует Windows COM или, на macOS, Apple Events (`do javascript`); Photoshop — оригинальный закрытый JavaScript-обработчик через Windows Script Host COM без поиска библиотеки типов .NET либо через Apple Events на macOS. На macOS при первом запуске система может запросить разрешение «Автоматизация»; не меняй его сам, сообщи пользователю, что включить. На macOS `document.save` (PSD) отклоняется до обращения к Photoshop: внешнее сохранение там вешает программу. Отдавай результат через `asset.export_png` и предложи пользователю сохранить PSD вручную. Для Photoshop доступна отдельно сопряжённая CEP-панель. Сообщай фактически возвращённые версию/канал — COM может выбрать другой установленный экземпляр, чем поиск файла.

В Photoshop размеры в пикселях, текст в пунктах. `document.open_copy` открывает/дублирует выбранные растровые изображения/PSD в собственный документ; изменения требуют возвращённый ID документа. `cleanup.fill` дублирует активный растровый слой и выполняет локальное встроенное Content-Aware Fill в ограниченном прямоугольнике. Проверь края и сохрани новый `.psd`. Платной генеративной заливки/изменения исходного документа нет.

Illustrator использует пункты и имена своих документов. `raster.trace` импортирует PNG/JPEG в новый документ, выполняет Image Trace и разворачивает редактируемые пути. `asset.export_svg` пишет новый SVG и возвращает текущее имя документа; экспорт способен изменить имя, поэтому следующий `.ai` сохраняй с возвращённой идентичностью. Проверь векторные элементы и отсутствие подмены развёрнутых путей растром. Произвольный пользовательский JavaScript и сброс проекта не доступны.
