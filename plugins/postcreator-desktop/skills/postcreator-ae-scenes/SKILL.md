Проверь `pc_desktop_status(app:afterEffects,live:true)` и `native.catalog`. Оригинальный маршрут по умолчанию использует документированный AfterFX `-r` на Windows и Apple Event `DoScriptFile` на macOS, закрытый обработчик и коррелированную квитанцию со сроком. Опциональная подписанная CEP-панель выбирается `POSTCREATOR_AE_TRANSPORT=panel`; отдельно установленный старый мост — только явно через `legacy`. Произвольные ExtendScript, меню, настройки и внедрение выражений не доступны. `native.do` получает точные аргументы каталога, возвращённый `context` экземпляра/файла/ревизии и настоящие ID композиции/слоёв. Даже одинаковые пути/ревизии другого проекта не заменяют токен текущего экземпляра.

После неопределённого таймаута сначала восстанови ожидающий запрос, затем выполняй другую операцию. Мост не позволяет слепой повтор и проверяет срок до позднего выполнения. Отсутствие модуля выполнения сценариев/права записи — требование приложения; не меняй безопасность/предпочтения автоматически. Для панельного `native_execution_uncertain` также сохраняй квитанцию отправки/срок и восстанавливай существующий результат без повторной мутации.

Подбери размер, fps, длительность, шрифты и точки монтажа по заданию. Создай именованную основную композицию и повторяемые вложенные секции. Используй управляющие нулевые слои, явных родителей, редактируемый текст/фигуры; анимируй трансформации/эффекты доступными операциями. Структура/цвета понятны для последующего редактирования.

Персонажные части вращаются около суставов; иллюстрации делятся на планы для параллакса; кинетический текст начинается с иерархии; логотип — с геометрии; бумага/постеры — с последовательности и сдержанной глубины; слайды/интерфейс — с акцентами по речи. Текст песни использует предоставленные временные метки слов или реальные аудиометки; сохраняй точные слова и проверяй границы строк. Локализованный текст измеряй/перекомпоновывай до переноса времени. Шрифт содержит нужные символы.

Перечитай состояние, отрендери первый/средний/последний кадры через `render.frame` с актуальными `context` и `compId`, изучи пиксели, сохрани новый `.aep` внутри каталога результатов. Устаревшее `comp` допустимо лишь при единственном совпадении имени/ID по каталогу. Рендер кадра не доказывает готовый MP4. Назови отсутствующие звук, эффект или экспорт.
