# Postcreator Desktop — локальные творческие редакторы

Отдельный локальный модуль для редактируемых сцен, графики, монтажа и эффектов. Включает12 оригинальных скиллов,30 команд и четыре MCP-инструмента. Нативные операции выполняются на вашем компьютере; для них не нужен облачный генеративный провайдер.

Начните с [установки](docs/INSTALL.md). Точные результаты и ограничения проверки находятся в [таблице возможностей](docs/CAPABILITIES.json). [Происхождение кода](THIRD_PARTY.md).

| Программа | Возможности | Требования |
| --- | --- | --- |
| Blender | Сцены, материалы, правка только цвета, сборка, выпуклое разрушение/физика, PNG, `.blend`, GLB | Фоновый Blender4.0+; выбранная сохранённая сцена/изолированный проект; сложные связанные цвета проверяются до изменения |
| After Effects | Композиции, слои, текст, маски, ключи, эффекты, кадр, новый `.aep` | Рабочие скрипты и право записи; Windows `AfterFX -r`, macOS Apple Event `DoScriptFile`; дополнительные панели/legacy выбираются явно |
| Photoshop | Новый документ/копия растра, текст, обычная Content-Aware Fill, PSD/PNG | Рабочий Windows COM, macOS Apple Events (PSD на macOS сохраняется вручную) или настроенная панель; настоящая версия проверяется ответом программы |
| Illustrator | Графика, обводка растра в векторы, SVG/AI | Рабочий Windows COM или macOS Apple Events |
| Resolve | Импорт, таймлайн, CDL/LUT, очередь/рендер, сохранение | Официальный SDK/Python, лицензия и актуальные идентификаторы проекта/таймлайна |
| TouchDesigner | Собственный узловой компонент и новый `.tox` | Установленная программа и явный запуск подключения |
| Premiere | Структура проекта, импорт, последовательности, сохранение, прямой экспорт | Подписанная панель и рабочее сопряжение; источник панели для версий24–25.5 |

Node24+ устанавливается отдельно. `bootstrap.mjs` ищет существующий Node24; загрузка новой среды автоматически не выполняется. `setup` копирует модуль в новый постоянный каталог и создаёт абсолютную конфигурацию. `setup --register codex|claude` добавляет только отсутствующее подключение; существующее или отключённое сохраняется.

После установки/обновления нужен новый чат или перезапуск клиента. Проверка путей/каталога не подтверждает живую связь. Сначала запросите состояние выбранной программы в режиме чтения.

Папка `runtime/` в репозитории готовится из канонических `desktop/src` и `desktop/native`. Упаковщик со флагом `--stage` синхронизирует её; сборка отклоняет расхождение байтов и ссылки в пути. Установочные архивы содержат полную локальную среду.
