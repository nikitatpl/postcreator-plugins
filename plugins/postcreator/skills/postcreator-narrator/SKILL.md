# Диктор и временные окна

Прочитай [выполнение](../postcreator/references/execution.md) и [требования к результату](../postcreator/references/production.md). Измерение/ограничение приходит от пользователя или активного плана. Обычная озвучка направляется в аудиоприложение.

Запиши текст по порядку, язык, точную конфигурацию голоса, окна, подачу и разрешённые паузы. Найди живую схему речевой модели/приложения и библиотеки голосов; сохраняй заданные ID и настройки. Профиль библиотеки не равен ID голоса поставщика. Используй совместимые возвращённые ID. Фото не позволяет клонировать голос; повтор не меняет голос.

Проверь настоящий маршрут измерения речи/длительности. Котируй каждый дубль с теми же моделью/входами/параметрами, что запуск. Веди строку учёта на реплику, различай длину файла и слышимую речь. Измеряй начальную/конечную тишину и речь реальными инструментами; скорость чтения годится только для черновика.

При превышении окна перепиши только эту реплику, сохраняя смысл, и повтори в разрешённом бюджете. Для короткой реплики добавь осмысленные паузы или измени текст, сохраняя весь хронометраж видео. Не режь слова, не меняй высоту/скорость без явного принятого запроса. Измерь исправление и сохраняй прошедшие оригиналы. Непрерывное чтение может быть одним запуском или последовательными частями при лимите модели; проверь стыки и постоянный голос.

Для аудио/видео проекта используй `probe_media_asset` и `transcribe_media_asset`. Отдельно показывай интервал первого/последнего распознанного слова и длину файла; прослушай точный текст. При монтаже сохраняй сдвиги. Отсутствие модели/исполнителя не позволяет назвать оценку измерением.

Для диктора поверх исходника используй предоставленное фото с согласия человека, точный текст/голос и реальную операцию Lipsync Studio. Сохрани заказанный видеоряд и звук. Проверь наложение изображения/видео, создай дикторский клип и скомпонуй по документированным позиции, размеру и времени. Не заменяй исходник говорящим портретом.

Выдай упорядоченные аудиофайлы или готовую композицию с измеренной длительностью и честными ограничениями проверки. ID задачи или утверждение времени без измерения недостаточны.
