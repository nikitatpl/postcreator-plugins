# Полный сценарий

Это письменная задача, без разрешения платной генерации. Подключённый чат Postcreator используется, если заказан, совместим и котирован. Собственный текст и чтение источников могут выполнить запрос. Последующий заказ видео направляется в соответствующий сценарий.

Определи тему, обещание зрителю, длительность, язык, доказательства и позицию рассказчика. Жанр задаёт результат — практическое решение/модель действий → бизнес/финансы; применение инструмента/вердикт → технический обзор; оценка конкретного материала → комментарий; хронология реальных событий → документальный фильм; доказательный разбор уголовного дела → реальное преступление; причинное «как/почему» → объяснение. Одно название отрасли жанр не выбирает. Существенную неоднозначность результата уточни до написания; компания/деньги не означают автоматически советы.

Прочитай только нужный раздел [жанров](references/genres.md) и сохраняй структуру. Факты берутся из предоставленных или доступных первичных источников. Обозначай неопределённость; не выдумывай цитаты, личные тесты/опыт, доход, квалификацию, спонсоров, признания и историю аудитории. Спонсорский блок нужен только по явному заданию и с подтверждёнными утверждениями.

Выдай три разных начала, затем один полный сценарий с временными отметками, конкретными визуальными/звуковыми указаниями и картой удержания. Вся длительность заполнена готовыми произносимыми абзацами, не планом или поручением другому автору. Время по естественной скорости чтения называй оценкой; исполненная речь измеряется только на аудиоэтапе. Указания описывают видимые кадры/графику, не скрытую инфраструктуру.

Проверь обещание/развязку, факты, причины/хронологию, повторы, переходы, произносимость, длительность и окончание. Недостающий факт укажи рядом с утверждением. Выдай полный текст на заказанном языке/в формате; ведущий, обложка и видео не генерируются без заказа.
