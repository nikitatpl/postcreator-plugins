# Изображения

Прочитай [правила выполнения](../postcreator/references/execution.md). При наличии каталога разреши выбранную `/image` или `/image-edit`.

Определи объект, назначение, соотношение сторон, композицию, точный видимый текст, стиль и необходимые референсы. Обычные обратимые решения принимай по заданию; уточняй только существенные недостающие входы. Сохраняй выбранную пользователем совместимую модель.

Используй `list_generation_models`, при необходимости `recommend_generation_model`, затем `get_generation_model_schema`. Выбирай доступную модель и поддержанный режим. Текстовое задание и настоящие вложения ChatGPT могут использовать прямой путь. Локальные референсы Codex/Claude Code загружаются и привязываются в выбранном Canvas. Для карточек товара, улучшения, удаления фона, дорисовки по маске и ракурсов прочитай `list_apps` / `get_app_schema`. Приложение Canvas не обязательно доступно через прямую генерацию.

Задай в промпте объект, композицию и область правки. Укажи изменения и роль каждого референса — внешность, форма товара, свет или расположение. Сохраняй запрошенный текст дословно. При дорисовке привяжи исходник и соответствующую маску по схеме приложения; маска является ассетом, не строкой URL.

Если заказана подготовка промпта серверным AI Assistant, выбери совместимые тип задачи/модель через `list_generation_presets`, запроси `quote_prepare_generation_prompt`, затем `prepare_generation_prompt`. Передай возвращённый ID задачи как `preparedPromptTaskId` в прямую котировку и запуск; одновременно `prompt` не передавай. Это отдельный платный этап, необязательный при достаточном собственном промпте.

Котируй, запускай и получай артефакт по общим правилам. Проверь реальное изображение — соответствие референсу, надписи, кадрирование и границы правки. При дефекте объясни коррекцию и котируй её в пределах разрешённого бюджета; не покупай дополнительные варианты молча. Выдай все заказанные изображения с понятными обозначениями.
