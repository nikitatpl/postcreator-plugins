# Творческое производство Postcreator

Используй подключённый MCP-сервер Postcreator. Имена с префиксом клиента сопоставляй по суффиксу; не выдумывай инструменты и не переключайся на постороннего медиапровайдера.

До генерации или изменения проекта прочитай [правила выполнения](references/execution.md). Они задают владение входами, цены, повторы и выдачу артефактов.

При наличии `list_creative_workflows` просматривай каталог, а `get_creative_workflow` разрешает точную выбранную команду — например `/image`, `/image-edit`, `/video`, `/video-edit`, `/canvas`, `/story`, `/character`, `/montage`, `/audio`, `/3d`, `/campaign`. Это чтение инструкций, без выполнения и списания. Схемы инструментов и живые каталоги приложений/моделей являются источником истины. Если старый сервер не предоставляет эти два инструмента, продолжай по включённым инструкциям и реально доступным инструментам. Не повторяй вызов неизвестного инструмента и не утверждай, что установка плагина добавляет возможности серверу.

Запрос идей или промпта остаётся текстовой задачей. Генерация требует намерения получить готовый материал. Сохраняй результат и количество; один клип не разрешает целый эпизод, кампанию или создание проекта.

Команда выбирает сценарий только при утвердительном намерении пользователя. Цитата, перевод, объяснение, обсуждение и явное отрицание команды не являются запуском. «Объясни /shot-cleanup, ничего не запускай» требует объяснения; «Не /ugc-flow, только озвучь текст» выбирает аудио. Если пользователь явно выбрал команду для производства, разреши её до выбора другого сценария. Голая команда означает выбор/просмотр, без покупки результата. Для обычной речи используй самое конкретное утвердительное намерение.

Примеры различения — «UGC с товаром и закадровой озвучкой без ведущего» выбирает товарное UGC; «обзор с автором в кадре» — обзор; «примерка и посадка» — примерку; «распаковка с реакцией» — распаковку; «покажи использование по шагам» — инструкцию при авторском/UGC формате; «встрой субтитры в ролик» — готовое видео с субтитрами. Историческая тема сама не выбирает видео без ведущего, ссылка товара сама не выбирает UGC, выбранный голос сам не требует измеренных дублей. Перевод текста субтитров остаётся текстом.

Отвечай на языке текущего запроса, по умолчанию на русском для русскоязычного диалога. Язык речи, надписей и субтитров задаётся заказом, а не языком технических инструкций. Не переводи ID инструментов/моделей, поля JSON, перечисления и необходимые API-литералы.

Сохранённые назначения применяй только по [правилам выполнения](references/execution.md). Последний явный запрос важнее настроек; одноразовый выбор проекта не обновляет постоянные предпочтения. Сохранённое автоматическое создание действует только на первую заказанную генерацию нового диалога и не разрешает дополнительные материалы или траты. Действующее разрешение на бюджет сохраняется — повторное подтверждение не требуется для уже разрешённого объёма, но точная котировка каждого платного запуска обязательна.

До полного производства прочитай [требования к готовому результату](references/production.md) и проверь возможности завершения. Локальные редакторы и установка относятся к отдельному Postcreator Desktop. Облачное подключение не управляет After Effects, Blender, Resolve, Premiere, Photoshop, Illustrator или TouchDesigner. Хостинг, исследовательская студия бренда, обученные инфлюенсеры и промоакции кредитов требуют настоящих отдельных сервисов; обычная генеративная модель их не доказывает. См. [границы возможностей](../../docs/CAPABILITY-BOUNDARIES.md).

При ошибке соединения/авторизации объясни повторное подключение через OAuth-интерфейс клиента. `get_account_status` показывает выданные права и отсутствие разрешения генерации. Повторную авторизацию выполняет пользователь; не проси пароль и не помещай токены в конфигурацию.

Начальный каталог `/mcp/agent` компактен. Если инструмент из сценария не показан, получи его через `get_tool_schema` и выполни возвращённым `executionTool` с `{name, arguments}`; это относится и к операциям из `nextCall`. Не объявляй возможности недоступными по одному начальному списку. Подробнее — в общих правилах выполнения.
