# Истории и персонажи

Прочитай [правила выполнения](../postcreator/references/execution.md), выбранную `/story` или `/character` при наличии каталога и живую схему приложения.

Для одного листа ракурсов используй `quote_character_sheet_to_chat` / `generate_character_sheet_to_chat` только с настоящими вложениями изображений ChatGPT. Это один коллаж, без записи персонажа. Локальные референсы Codex/Claude требуют выбранного проекта/Canvas, объявленной операции Character и загрузки/привязки.

Постоянного персонажа найди через `list_characters` / `get_character`; создавай или обновляй запись только по запросу. `bind_character_image` получает ассеты проекта и актуальные поля проверки конкурентных изменений. Разделяй референс внешности/стиля и композиции. Сохраняй принятую внешность, одежду, палитру и пропорции между кадрами, если история не требует изменений.

Для Story выбери разрешённый проект, прочитай `list_story_projects` / `get_story_project`, используй `create_story_project` / `update_story_project` с текущей типизированной схемой. Веди настройки, сценарий, персонажей, сцены, кадры, аудио и анимацию в возвращаемом формате; не заменяй богатый документ выдуманным плоским массивом кадров.

План кадра содержит назначение, объект/действие, место, композицию, длительность и звук. Явно фиксируй непрерывность. Планирование и Story CRUD отделены от платной генерации. Котируй каждый этап по настоящему маршруту и соблюдай общий разрешённый бюджет. Генерируй только необходимые варианты.

Привязывай готовые медиа проекта через `bind_story_media` со свежим `expectedUpdatedAt`. Приватный артефакт чата не является ID библиотеки проекта; ID задачи нельзя выдавать за привязку. Для последующего Canvas генерируй в выбранном проекте или импортируй реальные байты разрешённым способом.

При заказе редактируемого экспорта используй `export_story_to_canvas` с выбранным `boardId`. Его отсутствие может создать Canvas — это требует разрешённого создания. Экспорт не рендерит эпизод; для заказанного финального монтажа используй Montage. Выдай листы/кадровые медиа, доступную ссылку Story/Canvas и точный список недостающих кадров.
