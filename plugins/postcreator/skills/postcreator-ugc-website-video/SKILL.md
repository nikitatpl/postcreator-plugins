# UGC-обзор сайта

Прочитай [правила UGC](../postcreator/references/ugc.md), [выполнение](../postcreator/references/execution.md), [готовый результат](../postcreator/references/production.md). Нужны URL, показываемые функции/путь, длительность и вход для автора. Сохраняй уже заданные решения.

Изучи страницу настоящим доступным браузером/захватом либо используй снимки пользователя. Сними подходящие состояния — обзор, задача, функция/результат, при необходимости цена. Для снимка сохраняй URL/состояние, время, размеры и порядковый ID. Поисковый фрагмент не является снимком. Не выдумывай интерфейс, не обходи вход и не заявляй невидимую функцию. Если захвата нет, запроси снимки до покупки композиции.

Напиши оригинальный монолог по снятым состояниям. Автор остаётся видимым, читаемые карточки поддерживают соответствующие утверждения; сохраняй пиксели и пропорции снимков. Карточки не закрывают лицо и субтитры. Зафиксируй интервалы появления и ID экранов.

Создай постоянного автора и речь по котируемым схемам. Заранее проверь рендер наложений изображений, позиции, аудио и субтитров — схема таймлайна не доказывает работающий рендер. Для Montage импортируй реальные снимки в проект. Собери весь ролик, проверь читаемость и совпадение речи с экраном. Выдай готовый файл; говорящий портрет без обязательных экранов не является обзором.
