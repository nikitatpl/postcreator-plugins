# Сайты, приложения и игры

Разреши выбранную `/website-builder` при наличии каталога и прочитай [границы возможностей](../../docs/CAPABILITY-BOUNDARIES.md). Определи сайт, генеративное приложение или игру, сохраняя объём, владение исходниками, цель развёртывания и публикацию. Правка компонента/локального репозитория остаётся обычной разработкой.

До обещания хостинга проверь реальные создание/получение исходников, редактирование, среду/шаблон, сборку, развёртывание/статус, домен и живой результат. Для генеративного приложения нужны работающие авторизация посетителей и серверные права, перевод моделей/входов/котировок Postcreator, биллинг/идемпотентность, секреты, восстановление задач и выдача медиа. Игра требует действующих правил среды/ассетов/сохранения для заказанного режима игроков. Не переноси инструменты и схемы другого провайдера.

Выбери реальный маршрут. Codex/Claude Code с рабочими файлами могут написать полноценный проект и использовать выбранный/подключённый хостинг. При доступном Sites прочитай установленные `sites:sites-building` и `sites:sites-hosting` и их необходимые ссылки до инструментов, сохраняя Postcreator как выбранного поставщика ассетов. Не вставляй машинные пути кеша плагина. Следуй реальным регистрации, исходникам, сборке, развёртыванию/статусу и доступу установленного помощника. Явно выбранный другой хостинг важнее. Без кода/среды и сервиса создания живой продукт невозможен — объясни отсутствие и сохрани задание, не заменяя его макетом.

Заказанные/нужные изображения, видео, звук и игровые ассеты производи котируемыми маршрутами Postcreator. Получи реальные файлы и включи их по подходящим стабильным локальным/публичным путям. Приватный MCP URI не является публичным URL картинки. Публикуй ассеты настоящим контрактом хостинга с происхождением. Секреты Postcreator не размещаются в браузерном коде.

Реализуй настоящее поведение — игра запускает игровой цикл, редактор имеет рабочие контролы/результаты, сайт содержит содержание и заказанные переходы/формы. Следуй стилю/адаптивности; обработай загрузку, пустые данные, ошибки, успех. До визуалов игры зафиксируй ввод, состояния, победу/поражение/повтор, время и ассеты. Проверь цикл, изменение размера, ввод, управление звуком. Обложка/OG создаются по запросу; не покупай незапрошенные декоративные видео.

Генерация для посетителей использует только документированную серверную интеграцию Postcreator с авторизацией, ценой, повторяемыми запусками и восстановлением задач. MCP-подключение ассистента не является публичным SDK. Без такой интеграции заверши независимую заказанную разработку и точно назови заблокированную генерацию; декоративная кнопка не считается работающей. Сохранение данных — по запросу и доступному контракту, с валидацией и серверным хранилищем секретов.

Проверь предпросмотр реальным браузером/средой — основной путь, мобильный/настольный вид, читаемость, доступность, картинки и ошибки. Выполни подходящую сборку/функциональные проверки, включи нужные ассеты, убери заглушки. Локальный заказ выдаёт рабочий код и инструкции. Заказ хостинга использует реальное развёртывание и восстановление/опрос принятой задачи до успеха. Это внешний хостинг с ассетами Postcreator, не новый облачный сервис Postcreator.

Если будущий сервер предоставит настоящий builder, следуй точным типу/категории/шаблону/настройкам и владению исходниками. Реализуй поведение, содержание, адаптивность, доступность, состояния и метаданные; медиа только реальными котируемыми операциями. До развёртывания проверь поведение/безопасность/сборку и соблюдай разрешение публикации. Таймаут восстанавливается по принятой задаче.

Результат размещённого заказа — успешный живой URL, проверенное поведение и заказанный доступ к исходникам. Черновик, квитанция репозитория или медиапредпросмотр не являются готовым продуктом. Назови нерешённые ограничения без заявления полного паритета.
