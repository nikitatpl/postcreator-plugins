# Postcreator — создание медиа в ИИ-ассистенте

Плагин соединяет Codex или Claude с вашим аккаунтом Postcreator через **https://post-creator.ru/mcp/agent**. В пакет входят26 оригинальных скиллов и119 команд: изображения, видео, звук, истории, UGC, маркетинг, обложки, субтитры и анимация. Локальные редакторы доступны через отдельный Postcreator Desktop.

Начните с [понятного руководства](docs/USER-GUIDE-RU.md). Краткая настройка — [установка](docs/INSTALL.md); реальные зависимости — [границы возможностей](docs/CAPABILITY-BOUNDARIES.md).

## Состав

- `plugin.json` и `mcp.json` — переносимый формат Agent Plugins.
- `.codex-plugin/plugin.json` — пакет Codex; `.claude-plugin/plugin.json` и `commands/` — пакет Claude.
- `skills/` — инструкции; `docs/` — установка и проверка.
- Общий архив содержит оба плагина и каталоги установки для команды.

Все форматы используют полный MCP endpoint. Авторизация проходит в клиенте через ваш аккаунт. Токены и пароли в архив не включены.

## Использование

Пишите задачу на русском обычными словами: «Через Postcreator собери ролик с моим товаром и закадровой озвучкой». В Claude доступны команды вида `/postcreator:video`. В Codex можно явно выбрать скилл, например `$postcreator-video`.

Каталог содержит149 сценариев обоих плагинов и63 рецепта товара. Чтение каталога не запускает генерацию. Ассистент проверяет действующую схему, материалы, стоимость и возможность закончить работу. Уже согласованный бюджет сохраняется. Готовый результат нужно получить и проверить: квитанция о задаче его не заменяет.

## Сборка для команды

Из корня репозитория, установленным Node24:

```sh
npm run plugin:desktop -- --stage
npm run plugin:test
npm run plugin:suite -- --output ./artifacts/postcreator-suite-1.2.1.zip
```

Упаковщик использует явный список файлов, проверяет ссылки/пути, согласованность локальной среды и распространённые формы секретов. Одинаковые исходные байты дают одинаковый ZIP. `.env`, зависимости, журналы, доказательные медиа и веса моделей в пакет не попадают.

Новые серверные возможности требуют отдельного релиза Postcreator. Локальная установка плагина не обновляет сервер. Публичная публикация в каталоге расширений — отдельный процесс; здесь подготовлен пакет для локальной установки и команды.
