# Установка облачного плагина

Используйте общий архив или доверенный репозиторий. Распакуйте архив в новую постоянную папку и сохраните скрытые каталоги. В каждом плагине манифесты, `skills/` и файлы MCP должны оставаться вместе.

## Codex

Добавьте распакованный общий пакет как локальный каталог плагинов в интерфейсе Codex. Поддержанный CLI также позволяет выполнить:

```sh
codex plugin marketplace add /полный/путь/к/общему-пакету
codex plugin add postcreator@itsalab-creative
```

Войдите в свой аккаунт Postcreator, когда клиент запросит авторизацию. Рекомендуемый адрес подключения — `https://post-creator.ru/mcp/agent`. Для доступности платных инструментов нужны соответствующие права аккаунта. Состояние показывает `get_account_status`; обновление прав выполняется через интерфейс авторизации.

## Claude Code

Временная проверка доверенного каталога плагина:

```sh
claude plugin validate ./plugins/postcreator
claude --plugin-dir ./plugins/postcreator
```

Постоянная установка из общего пакета:

```sh
claude plugin marketplace add /полный/путь/к/общему-пакету
claude plugin install postcreator@itsalab-creative
```

Откройте `/mcp` для авторизации и проверки инструментов. Примеры вызова — `/postcreator:image`, `/postcreator:video`, `/postcreator:audio`. Отдельный архив облачного плагина является папкой плагина; общий архив дополнительно содержит корневой каталог установки.

## ChatGPT и другие клиенты

Клиент с поддержкой Agent Plugins читает `plugin.json`, `skills/` и `mcp.json`, затем выполняет авторизацию. Для пользовательского удалённого MCP-подключения ChatGPT используется полный URL и поддержанный интерфейс настройки клиента. Доступность зависит от клиента и его прав. Этот пакет не означает автоматическую публичную регистрацию расширения.

## Материалы и выдача файлов

Поддержанная текстовая генерация может работать без проекта. Новые вложения прямого маршрута используют настоящие ChatGPT `files` с выданными клиентом `download_url`. Произвольный URL будет отклонён. Локальный путь, base64 или ID другого клиента не заменяют такую привязку.

Готовый результат своего аккаунта можно передать в следующий этап через `artifactInputs` с `{taskId,index,inputId}`. Проверяются завершение исходной задачи, владелец, срок, тип и размер. Котировка и запуск используют одинаковые входы.

В Codex/Claude новый локальный референс загружается через `create_file_upload`: агент получает одноразовую ссылку, отправляет туда файл с диска одной командой `curl -T` (до 50 МиБ) и передаёт полученный объект `file` в `upload_media_asset` (затем `bind_media_asset`) или прямо в `generate_to_chat`. Base64 до 8,000,000 символов остаётся запасным путём для серверов без этого инструмента. Запрет пользователя на создание проекта имеет приоритет над сохранёнными настройками.

Цена берётся из точной котировки. Предел уже разрешённого бюджета учитывается для всех этапов. После запуска ассистент проверяет статус и получает реальный файл/части файла. Идентификатор задачи не является результатом.

## Проверка без расходов

Прочитайте `get_account_status`, `list_generation_models`, `list_apps` и `list_creative_workflows`, изучите схему и получите цену. Каталог сценариев постраничный: продолжение указано в `nextOffset`. Доступность серверных инструментов проверяется по живому подключению, а не по версии ZIP.

Подробно: [руководство на русском](USER-GUIDE-RU.md), [два плагина](SUITE.md), [границы](CAPABILITY-BOUNDARIES.md).

Если установлена старая версия плагина, обновите её после серверного релиза и перезагрузите список инструментов. Компактный каталог использует `get_tool_schema` для остальных операций, включая Canvas и апскейл Topaz/Bloom; вручную настраивать enabled_tools не требуется. Старый endpoint `/mcp` продолжает работать.

Если для обхода обрезанного каталога ранее добавлялся временный `enabled_tools`, после выкладки `/mcp/agent` и обновления плагина снимите именно этот временный список в настройках MCP плагина и перезагрузите клиент. Старый список может скрывать `search_tools`, `get_tool_schema` и `call_*`. До серверной выкладки оставьте обходную настройку. Постоянные пользовательские ограничения доступа автоматически не удаляются.
