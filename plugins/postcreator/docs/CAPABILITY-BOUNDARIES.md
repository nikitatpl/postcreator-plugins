# Доступные возможности и зависимости

Скиллы содержат оригинальные инструкции. Реальные возможности определяет подключённый сервер/редактор: инструменты, права, схемы моделей, ограничения входов и доступность обработки. Версия ZIP не подтверждает обновление сервера.

| Результат | Действующий маршрут и условие |
| --- | --- |
| Изображение, товарная карточка, обложка | Поддержанная модель и настоящий референс; получить и проверить изображение |
| Видеоклип/вариант исходника | Действующая видеомодель или Video Edit/motion-control; проверить действие, звук и длительность |
| Персонаж/референс-лист | Character Constructor и библиотека; обычный персонаж не является обучением новой модели личности |
| Озвучка, музыка, lip sync | Схема подходящего приложения и совместимые голосовые профили; речь измеряется по реальному аудио |
| Полная история/выпуск | История, отдельно согласованные медиаэтапы и финальная сборка; экспорт Story не заменяет фильм |
| Монтаж, титры и анимация | Настоящие mediaId, текущая версия, доступный worker и `renderFeatures` |
| Русские речевые субтитры | Распознавание с реальными словами/интервалами, сверка с аудио, текстовые клипы и проверка итогового MP4 |
| Настоящие кадры для анализа | `inspect_video_frames` возвращает PNG и фактическое время; извлечение не является автоматическим смысловым анализом или историей аналитических задач |
| Скриншоты сайта | Реальный браузер/снимки пользователя; изображение выдуманного интерфейса не заменяет сайт |
| Точные размеры/ZIP/специальная обработка | Доступные файловые инструменты ассистента и проверенный локальный результат |
| Бренд и сведения о товарах | Лёгкий список наборов, полные данные через `get_brand_kit`, записи с контролем версии; исследование одной разрешённой публичной страницы не сохраняет бренд автоматически |
| Аудит рекламы | Настоящие исходные показатели или предоставленные данные; не выдумываются клики/выручка/опыт покупателей |
| Сайт/браузерное приложение | Инструменты разработки, сборки/предпросмотра и выбранный подключённый хостинг |
| Генерация для посетителей сайта | Реальная серверная авторизация, оплата, задачи и выдача; секреты ассистента не становятся публичным SDK |
| Локальная редактируемая сцена | Отдельный desktop-модуль, рабочая программа и её настоящий каталог операций |
| Специализированная замена голоса, чужие акции/сброс кредитов | Требуют собственных реальных сервисов; TTS, баланс и обычная генерация не доказывают их наличие |

## Монтаж и распознавание

Новый renderer объявляет стилизованный текст, читаемые титры и линейные ключи по абсолютному времени таймлайна. Проверяйте действующий сервер: старый worker может не иметь этих возможностей. Звук исходного видео требует явного аудиоклипа того же файла.

Измерение/распознавание/кадры принимают доступные проектные аудио и видео до50МиБ/300секунд. Требуются FFmpeg/FFprobe, Python/faster-whisper и установленная локальная модель. Модель не скачивается во время запроса. Неточные распознанные слова нельзя выдавать за проверенную речь; имена и числа сверяются с аудио.

## Локальные редакторы

Подготовленный код проверяется отдельно от подключения приложения. На тестовой машине получены настоящие файлы Blender, Photoshop, Illustrator и Resolve. AE сообщает о проблеме Scripting plugin, подписанная панель Premiere ещё не подключена, TouchDesigner отсутствует. На других компьютерах выполняется собственная диагностика версии/лицензии/интерфейса.

Windows COM и штатный Windows-запуск AE на macOS заменены маршрутом Apple Events (Photoshop, Illustrator, After Effects); он проверяется отдельно на установленной версии и требует разрешения «Автоматизация». Приложения, лицензии и настройки безопасности автоматически не устанавливаются/не меняются.
