# Облачный плагин и локальный модуль

Общий пакет включает два независимых плагина. **Postcreator** работает с вашим аккаунтом, медиа, Canvas, историями, монтажом и брендами. **Postcreator Desktop** работает с программами вашего компьютера через отдельный локальный MCP-сервер. Можно установить нужную часть или обе.

В общем ZIP находятся два корневых каталога установки, обе папки плагинов, оригинальные скиллы, команды и полная локальная среда. Скрытые каталоги сохраняются при распаковке. Отдельный облачный ZIP не содержит локальный модуль.

Codex устанавливает скиллы через каталог плагинов, а локальный сервер регистрируется командой `setup --register codex` с абсолютными путями этой машины. Claude использует собственный манифест локального сервера; `bootstrap.mjs` находит существующий Node24. При отдельной регистрации Claude выбирайте один маршрут, чтобы не дублировать сервер.

После установки/обновления откройте новый чат и проверьте реальные инструменты. Каждому коллеге нужны собственная облачная авторизация, Node24, установленные программы и их лицензии/интерфейсы скриптов. Найденный путь к программе не доказывает рабочее подключение.

Новые серверные возможности доступны после отдельного релиза. Распознавание использует предустановленную модель и не загружает её при пользовательском запросе. Обычные генеративные операции используют действующие схемы и точные цены в рублях.

Полная инструкция: [руководство](USER-GUIDE-RU.md), [подключение](INSTALL.md), [проверяемые возможности](CAPABILITY-BOUNDARIES.md).
